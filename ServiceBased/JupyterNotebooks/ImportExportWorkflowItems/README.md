# Export and Import Workflow Manager Items Asynchronously

This Jupyter Notebook sample will export an existing Workflow Manager Item, create a new workflow item, then import the configuration to the newly created item in the same GIS. All this work will be done asynchronously.

## Instructions

1. Ensure the requirements below are met on the machine where the notebook will be run.

2. Download the `Workflow Manager - Import Export Items Asynchronously.ipynb` notebook.

3. Run the notebook using ArcGIS Pro, in the Jupyter Notebook environment, or run in your IDE of choice.

## Requirements

- ArcGIS API for Python >= 2.x
